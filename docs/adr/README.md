# Architecture Decision Records

This directory holds ADRs for ReferralPro — short records of significant architectural decisions, why they were made, and what alternatives were considered.

## Format

One file per decision: `NNNN-short-title.md` (zero-padded, sequential). Suggested sections:

```markdown
# NNNN. Title

Status: Proposed | Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context
What problem or forces led to this decision.

## Decision
What was decided.

## Consequences
What this makes easier or harder; trade-offs accepted.
```
